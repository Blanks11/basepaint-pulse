=== Material Longshadow Blue Cursor Set ===

By: J (http://www.rw-designer.com/user/48934) jugalmistry99@gmail.com

Download: http://www.rw-designer.com/cursor-set/material-blue-1

Author's description:

This is a recolor of my previous set [http://www.rw-designer.com/cursor-set/material-longshadow Material Longshadow [[cursor:101078]]]. Drawn and cursorified using RW Paint and RW Cursor Editor.

Unfortunately I released the original set in 2017 and people wanted recolored versions but I was not available so there's that

A bright color palette with subdued grey, to make the color pop. I've ensured to keep everything round to make it look smooth and pleasing.

Consists of the Colors:
Amber, Blue, Lime, Pink and Red which are a part of the material design color palette.
